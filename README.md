# Robert Wu — Landscape Architecture Portfolio

A responsive GitHub Pages portfolio template designed for landscape architecture and architecture work.

## Publish on GitHub Pages

1. Upload every file and folder in this directory to the repository root.
2. Go to **Settings → Pages**.
3. Select **Deploy from a branch**.
4. Choose **main** and **/(root)**, then save.

## Add Campus Acupuncture images

Open:

`assets/projects/campus-acupuncture/`

Add these image files:

- `cover.jpg`
- `concept.jpg`
- `masterplan.jpg`
- `section.jpg`
- `render-01.jpg`
- `render-02.jpg`
- `detail.jpg`

Then edit `index.html` and `project-acupuncture.html`, replacing placeholder paths such as:

`assets/projects/acupuncture.svg`

with:

`assets/projects/campus-acupuncture/cover.jpg`

Use lowercase file names without spaces. JPG or WebP is recommended. Export large images around 2000–2800 px wide and compress them before uploading.

## Important edits

- Replace `your.email@example.com` in `index.html`.
- Confirm project dates, credits and roles.
- Replace all SVG placeholders with portfolio images.
