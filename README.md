# Robert Wu — Landscape Architecture Portfolio

A static portfolio template designed for GitHub Pages. It uses only HTML, CSS and vanilla JavaScript.

## Quick start

1. Replace `your.email@example.com` in `index.html`.
2. Replace the SVG files inside `assets/projects/` with your exported drawings or renderings.
3. Edit project titles and descriptions in `index.html`.
4. Duplicate `project-template.html` for each project and update its content.
5. Upload the entire folder to a GitHub repository.
6. In GitHub: **Settings → Pages → Deploy from a branch → main / root**.

## Recommended image export

- Hero/project covers: WebP or JPG, 2400–3200 px wide.
- Plans and sections: PNG or WebP, 2200 px wide minimum.
- Keep each file under roughly 1.5 MB where possible.
- Use lowercase filenames without spaces.

## Main visual system

- Warm paper background
- Muted forest green
- Editorial serif headings
- Fine architectural rules and generous white space
- Responsive layout for desktop, tablet and mobile
